# Legacy archive

`original-patente-setup-2026-10-22.zip` is a snapshot of `Client/` and `Server/`
exactly as they were before the SH Digital Studio rebuild (the Easy Bangla
Patente quiz/course platform the setup was originally created for).

- `node_modules`, build output and **all `.env` files are excluded**, so the
  archive contains no secrets.
- The old quiz/course/student code, its images and its npm packages have been
  removed from `Client/` and `Server/`. This zip is the only remaining copy.
- Nothing in this folder is used by the application. Delete the folder
  whenever you no longer need the old code for reference.
